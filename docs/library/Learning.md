## 🌐 External Resources

### Git & GitHub

- [GitHub Skills](https://skills.github.com/) - Interactive courses by GitHub.
- [Pro Git Book](https://git-scm.com/book/en/v2) - The definitive guide to Git.
- [Conventional Commits](https://www.conventionalcommits.org/) - Specification for commit messages.

### Web Development

- [MDN Web Docs](https://developer.mozilla.org/) - Documentation for HTML, CSS, and JS.
- [JavaScript.info](https://javascript.info/) - Modern JavaScript tutorial.
- [Frontend Masters](https://frontendmasters.com/learn/) - Detailed learning paths.

### AI & Agentic Coding

- [AGENTS.md Specification](https://agents.md/) - The open agent-instruction convention this repository follows.
- [Claude Code Documentation](https://code.claude.com/docs) - Agentic coding from the terminal, IDE, or CI.
- [Prompt Engineering Guide](https://www.promptingguide.ai/) - Mastering AI prompts.

### Technical Writing

- [Google Technical Writing Courses](https://developers.google.com/tech-writing) - Free courses for engineers.
- [Write the Docs](https://www.writethedocs.org/) - Community for documentation.

## 🛠️ Recommended Tools

- **VS Code**: The recommended IDE for this project.
- **Postman / Insomnia**: For API testing and exploration.
- **Docker**: For containerized development environments.
- **Mermaid Live Editor**: For creating diagrams in markdown.
