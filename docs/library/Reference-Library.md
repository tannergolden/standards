## 🎯 Our Library Intent

The library holds the **transferable knowledge** of this repository: primers and command references that stay useful no matter which project you build on top of the template. Category guides tell you what _this repo_ does; library guides teach the skills those processes assume.

- **Primers**: Refreshers on the concepts our workflow builds on.
- **References**: Copy-paste commands for the daily loop and emergencies.
- **Growth**: Curated external resources for going deeper.

Looking for repository-specific lookups instead - the label taxonomy or the A-Z glossary? Those live in the [&#x1F4D8; References hub](../references/References.md); this library holds the transferable skills.
