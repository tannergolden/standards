## 💡 What This Folder Is For

[`action.yml`](action.yml) keeps the old address, `tannergolden/standards/actions/open-pr@v1`, working for a caller pinned to v1. It declares the same inputs and outputs as the action, which moved to [`.github/actions/open-pr/`](../../.github/actions/open-pr/README.md), and forwards every one. Call the new address instead: the forwarder goes at the next major version.
