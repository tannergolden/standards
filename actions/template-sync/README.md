## 💡 What This Folder Is For

[`action.yml`](action.yml) keeps the old address, `tannergolden/standards/actions/template-sync@v1`, working for a caller pinned to v1. It declares the same inputs and outputs as the action, which moved to [`.github/actions/template-sync/`](../../.github/actions/template-sync/README.md), and forwards every one. Call the new address instead: the forwarder goes at the next major version.
