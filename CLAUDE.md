# Standards: notes for Claude

Standing rules from the owner, for every session that works on this repository.

## Nothing private is ever named here

This repository is public, and so is everything it publishes. Apart from the template, tannergolden/repo, which
these documents name by design, no private repository of this account is ever named, linked or described here:
not in a file, a commit message, a pull request's title or description, an issue, a comment, a release note or a
workflow's output.

- Speak of such a repository by its role, such as "a repository generated from the private template", never by its
  name.
- Before every commit and every pull request, read the diff and the message for a private repository's name.
